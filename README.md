# Mandarin Trail — แผนที่คำจีน

เว็บฝึกจีนตัวย่อสำหรับผู้เรียนชาวไทย ใช้ต้นไม้คำเป็นจุดเริ่ม พร้อมพินอิน คำแปลไทย เสียง ประโยค ทบทวน และการเขียน รองรับมือถือและคอม

## ฟังก์ชัน

- `#map`: ต้นไม้ต่อเนื่อง แตก/ยุบกิ่ง ลาก/ซูม ค้นจีน/พินอิน/ไทย และรายละเอียดที่เปิดทันทีบนมือถือ
- `#sentences`: แนะนำตัว บอกจุดหมาย ขอสิ่งของ บอกกิจกรรม และถามความหมายของทุกคำในคลัง; ประโยคที่เลือกเก็บใน URL
- `#review`: ทบทวนรอบละ 3 ข้อ เฉลยหลังตรวจ ป้องกันนับซ้ำ เริ่มใหม่ได้ โดยไม่บันทึกผลระยะยาว
- `#speaking`: 2 สถานการณ์ / 6 คำถาม อัด–หยุด–ฟังเสียงในเครื่อง หยุดเมื่อครบ 60 วินาที และคืนสิทธิ์ไมค์เมื่อออก
- รายละเอียดคำ: ฟังปกติ/ช้า พร้อมสถานะผิดพลาดและลองใหม่ เปิดลำดับขีด/ลากเขียนได้ทุกตัวในคำปัจจุบัน

ข้อมูลปัจจุบัน **149 คำ / 125 ตัวอักษร** พร้อมไฟล์ลำดับขีดในเครื่อง หน้าและลำดับขีดใช้จากแคชได้หลังโหลดสำเร็จครั้งแรก เสียงขึ้นกับ voice ในเครื่องหรือเครือข่าย ไม่มีบัญชี แผนที่ความจำ SRS ใหม่ หรือคะแนนเสียงอัตโนมัติ

ลิงก์เดิม `#learn`, `#practice`, `#explore` และ bookmark เก่าอื่นเข้าแอปเดิมได้ ไม่ย้ายหรือลบ progress เก่า

โค้ดอยู่ใน `src/features/bloom/` และ [ผลตรวจ/ข้อจำกัด](docs/bloom/VERIFICATION.md) / [ขอบเขตข้อมูล](docs/bloom/CONTENT.md) / [test cases](docs/bloom/BLOOM-test-cases.xlsx)

## หน้าฝึกเดิม

| หน้า | ทำอะไร |
|---|---|
| วันนี้ | เปิดมาเห็นลำดับขีดทันที ระบบเลือก **5 ราก** ด้วย SRS แล้วสุ่มลำดับครั้งเดียวและล็อกไว้ทั้งวัน |
| ฝึก | ควิซ 5 ข้อและฝึกเขียนจากสิ่งที่เคยเรียนเท่านั้น ตัวเลือกเพิ่มเติมซ่อนไว้หลังโจทย์ |
| ฝึกจากบทเรียน | ดึงคำศัพท์และวลี 15 บทจาก `chinese.icejuk.dev` แล้วตรวจการเขียนทีละตัวอักษร มีสำเนาออฟไลน์ใน PWA |
| ค้น | ช่องเดียวค้นได้ทั้งตัวจีน พินอิน และภาษาไทย ครอบคลุมราก **115 ตัว** กับอักษร **167 ตัว** |
| เข้าใจตัวอักษร | แผนภาพส่วนประกอบแบบซ้อนชั้น (您 → 你 + 心 → 亻 + 尔) + คำอธิบาย + ลำดับขีดอยู่ครึ่งบนของจอ |

ชุดของวันและตำแหน่งที่เรียนค้างถูกจำไว้ในเครื่อง การ์ดจะอัปเดต SRS เฉพาะเมื่อผู้เรียนกดให้คะแนนตัวเอง ไม่ถือว่า “จำได้” จากการเปิดดูเฉยๆ มีชุด ⭐ "ยังไม่แม่น" เก็บใน localStorage — ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์

หน้าแตกตัวอักษรเล่นลำดับขีดแยกเป็นก้อนตามราก เช่น **河 = 氵 3 ขีด → 可 5 ขีด** พร้อมไฮไลต์ส่วนประกอบที่กำลังเขียน และ fallback เป็นการเล่นทั้งตัวเมื่อรูปย่อทำให้แบ่งอย่างปลอดภัยไม่ได้

## รัน

```bash
npm install
npm run dev
```

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | typecheck + bundle + gen service worker |
| `npm test` | Vitest — เทสคุมความถูกต้องของข้อมูลทั้งคลัง |
| `npm run strokes` | ดึงข้อมูลลำดับขีดของตัวที่ใช้จริงเข้า `public/strokes/` (ต้องรันใหม่ทุกครั้งที่เพิ่มราก/ตัวอักษร) |
| `npm run sync:chinese` | อัปเดตแบบฝึกจาก `chinese.icejuk.dev` และสร้างข้อมูลลำดับขีดของคำใหม่ให้ครบ |

## Deploy

โปรเจกต์พร้อมสำหรับ Vercel แล้ว (`npm run build` → `dist/`) และ GitHub repo อยู่ที่
[`icejuk/chinese-radical`](https://github.com/icejuk/chinese-radical) เป้าหมายโดเมนคือ **`radical.icejuk.dev`**

## ข้อมูล

- `src/data/radicals.ts` — ราก 115 ตัว + ส่วนบอกเสียง (声旁) 24 ตัว เขียนมือทั้งหมด
- `src/data/hanzi.ts` — ตัวอักษร 167 ตัว พร้อม `parts` และคำอธิบายการประกอบ
- `src/data/strokeIndex.ts` — **สร้างอัตโนมัติ** ด้วย `npm run strokes` มีทั้งรายชื่อตัวและจำนวนขีดจริง ห้ามแก้มือ
- `src/data/radicals.test.ts` — 13 เทส: คุม `parts`, ข้อมูลซ้ำ/วนลูป, ไฟล์ลำดับขีด และข้อยกเว้นการแบ่งกลุ่มขีด
- `src/lib/session.test.ts` — เทสชุดประจำวันตามเวลาท้องถิ่น, การ resume, due และควิซตามบทเรียน

## ทำงานออฟไลน์ได้

ไม่มี CDN / ฟอนต์ / สคริปต์ภายนอกเลย ข้อมูลลำดับขีดถูก precache ไว้ใน service worker
ยกเว้นเดียวคือเสียงอ่านจีนที่ตกไปใช้ Google Translate TTS เมื่อเครื่องไม่มี voice จีน (แคชไว้หลังเล่นครั้งแรก)
