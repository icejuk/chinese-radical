# สามแนวทางใหม่สำหรับเลือกก่อนพัฒนา

พรีวิว: `three-directions.html` — ใช้ mock words ชุดเดียวกัน และ interaction จาก `map-preview.js`

| แนวทาง | รูปแบบ | Layout คอม | CSS |
| --- | --- | --- | --- |
| ATLAS | ขาว/น้ำเงิน, การ์ดชิดซ้ายและเส้นขอบนำสายตา, grid จาง | แผนที่ซ้าย พจนานุกรมขวา | data-theme=atlas |
| ORBIT | navy/lavender, labels ลอย, เส้นทาง active เด่น, hub วงกลม | รายละเอียดซ้าย แผนที่ขวา | data-theme=orbit |
| คำต่อคำ | กระดาษอุ่น, ตัวจีนแนวลายมือเมื่อเครื่องมีฟอนต์, คำขีดเส้นใต้ | แผนที่เต็มความกว้าง รายละเอียดแนวนอนด้านล่าง | data-theme=paper |

มือถือทั้งสามแบบใช้แผนที่เหนือรายละเอียด เพื่อให้ตัวควบคุมไม่ถูก panel บัง
กรอบคอมในหน้าตัวเลือกย่อให้ดูได้ใน panel แคบ กดเปิดเต็มหน้าเพื่อดูแยกได้

ไฟล์:
- three-directions.html: หน้าตัวเลือกและ device switch/iframe
- design-directions.css: องค์ประกอบแต่ละแบบ แยก data-theme ชัดเจน
- map-design-preview.html: shared skeleton โหลด CSS เพิ่ม
- map-preview.js: อ่าน theme/device จาก URL และเปลี่ยน branding; zoom/pan ชุดเดิม

ขอบเขต: ตัวเลือก design ทั้งสามยังใช้พิกัด mock เพื่อเทียบ appearance/composition ไม่ใช่ production layout engine; ยังไม่ย้ายเข้า src และไม่ commit

## ORBIT: ขยายคลังคำหลังเลือกแนวทาง B

- `orbit-library.js` (ES module) อ่านชุดข้อมูลจาก `src/features/bloom/seed.ts` ผ่าน Vite; ไม่แก้ production seed
- คำไม่ซ้ำ 63 คำและ hub 9 ตัวในพรีวิว มีจุดเริ่มสำรวจ 8 กลุ่ม: 学、生、日、人、家、水、木、休 (活 เป็นกิ่งต่อของ生活)
- “เลือกกลุ่ม” แสดงจำนวน/ตัวอย่างพร้อมพินอินและไทย; “ดูทั้งแผนที่” แสดงทุก node บน canvas เดิม
- รายการคำในรายละเอียดของตัวอักษรคิดจาก actual string membership จึงเห็น 人 ทั้ง16คำ แม้บางคำมี parent หลักในกิ่งอื่น
- ตัวเลขต่อกลุ่มอาจซ้ำกัน แต่ยอดรวม63ไม่นับคำซ้ำ
- 4–240% สำหรับ ORBIT เพื่อรองรับขอบเขตแผนที่ใหญ่; +/− เพิ่มลดต่อจาก scale ปัจจุบัน
- ใช้ตำแหน่ง mock เป็นกลุ่มวงรอบ hub; ยังไม่ใช่ตัวจัดกิ่งอัตโนมัติของ production
- หน้าภาพรวมกลุ่มเป็นทางลัดในการเลือกกิ่ง ไม่ได้เปลี่ยน URL หรือแบ่งคำเป็น pagination
- คลังนี้ยังไม่ใช่หลักสูตร 2,000 ตัว และยังไม่ได้ตรวจคำแปลครบโดยเจ้าของภาษา

ตรวจพรีวิว: หัวเรื่อง63คำ/8กลุ่ม, 人 แสดงรายการ16คำ, ซูม100→120% ผ่าน browser UI; JavaScript syntax และ diff whitespace ผ่าน
