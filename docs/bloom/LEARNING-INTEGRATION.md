# Mandarin Trail: เชื่อมคำใหม่เข้าทั้งสามเมนู

อัปเดต 20 ตุลาคม 2026 · พรีวิวในเครื่อง ไม่มี commit/push/deploy ในงานนี้

## ผลที่ต้องได้

คำศัพท์ทั้ง 149 คำต้องเลือกจากหน้า คำสู่ประโยค / ทบทวน / ฝึกพูด ได้ มีจีน พินอิน ไทยในตัวเลือก เลือกจากตัวตั้งต้น 14 ตัวหรือเลือกทุกคำได้ เมื่อสลับเมนูต้องคงคำและตัวตั้งต้นไว้

## ข้อมูลและขอบเขต

- คำศัพท์ใช้ `catalog.ts` และ graph ชุดเดียวกับแผนที่ ไม่สร้างรายชื่อคำใหม่แยกอีกชุด
- ประโยคเฉพาะคำ 137 รายการจาก practice.ts และ practiceExamples.ts
- ประโยครูปแบบเดิม 4 ชุดครอบคลุมอีก 13 คำ และใช้เป็นตัวอย่างฝึกพูดร่วมกัน
- รวม 149 คำมีประโยคใช้งานแล้ว (นับคำซ้ำระหว่าง pattern และตัวอย่างครั้งเดียว) ดู CONTENT-COVERAGE.md สำหรับสถานะตรวจภาษา
- ทุกคำเข้าแบบทบทวนได้ รอบละไม่เกิน 3 คำ เลือกชุดถัดไปหรือทวนชุดเดิมได้ ไม่มี SRS หรือบัญชีเพิ่ม

## การทำงานที่นักพัฒนาต้องรักษา

1. `practiceWords(c:月)` คืนเฉพาะคำที่มี 月 จริง; `practiceWords(w:手机)` ให้ 手机 เป็นคำแรก; ไม่ระบุ context จะใช้ทุกคำ
2. URL `#speaking?word=w:月亮&root=c:月` ต้องเปิดคำและตัวตั้งต้นได้หลัง reload เช่นเดียวกับอีกสองเมนู
3. เลือกคำต้องหยุดเสียงเดิม และรีเซ็ตรอบ/ตัวอย่าง/ตัวอัดเสียงผ่าน component key
4. เลือกรูปประโยคใหม่กับคำเดิมต้องอัปเดตได้ ไม่พึ่ง remount จาก word ID อย่างเดียว
5. key ของรอบทบทวนต้องเป็นเลขรอบ ไม่ใช่ offset อย่างเดียว: ชุดที่มี 3 คำจะมี offset 0 เหมือนเดิม แต่ยังต้องเริ่มรอบใหม่ได้
6. ปุ่มคำกลับต้นไม้เรียก `onMap(wordId)` เพื่อใช้ navigation เดิม ไม่แทนที่ graph หรือเปลี่ยนเป็นหน้าแผนที่แยก
7. เสียงและตัวอัดเสียงใช้ implementation เดิม ไม่มีการอัปโหลดเสียงผู้เรียนหรือเพิ่มคะแนนความแม่นยำ

## CSS

`.bl-practice-picker` เป็น CSS grid สองคอลัมน์ กว้างเท่าคอนเทนต์ มี `min-width:0` บน label และ select กว้าง 100% ป้องกันชื่อยาวทำให้หน้าล้น ที่ 700px ลงมาเปลี่ยนเป็นหนึ่งคอลัมน์ พื้นหลัง #192236 เส้น #35415b; select พื้น #101624 และข้อความ #e8edf7 ความสูงอย่างน้อย 48px

`.bl-answer-example` ใช้พื้น #202a3f และข้อความ #e8edf7 ทั้งจีน พินอิน ไทย แทนสีเขียวจากธีมเดิมที่จมกับพื้นมืด

## ตรวจรับและข้อจำกัด

Automated: 76 tests / 10 files และ production build ผ่าน รวมการตรวจ metadata และ stroke files ทุกตัวในคำศัพท์เดิมด้วย

Browser: เลือก 月 → 月亮 ได้ประโยค 今晚的月亮很美。 เปลี่ยนถามความหมายและกลับรูปประโยคเดิมได้ คงคำเมื่อไปทบทวน ตอบสามข้อได้ 3/3 และเริ่มใหม่กลับเป็น 0/3 ได้ เลือกทุกคำแล้วเปลี่ยน 手机 เปิดตัวอย่างฝึกพูด 这是我的手机。 ได้ ทั้งสามช่องภาษาใช้สีข้อความอ่อน บน viewport 320px ไม่มี horizontal document overflow และ select อยู่ในขอบจอ

ยังไม่ใช่หลักสูตรครบ 2,000 ตัวอักษร มีประโยคใช้งานครบทุกคำใน catalog แล้ว แต่ยังไม่ได้ตรวจเนื้อหาโดยเจ้าของภาษา การตรวจ viewport เป็น browser simulation ไม่ใช่ทดสอบไมค์/เสียง/สัมผัสบนมือถือจริง การเผยแพร่และ commit/push ต้องทำเมื่อผู้ใช้สั่ง
